1商品ずつの内容

はじめての方へ3つの手順で使えます
  1. 商品登録でバーコードを読み取り、価格と数を入れて「在庫に登録」。
  2. 在庫リストで商品にチェックを入れ、値札・POPで印刷。
  3. 売れたら在庫リストの −、入荷したら ＋。なくなったら 🛒 で注文。

画面の右上の テレビを 押すと、おまけの ゲームが ひらきます。アプリを 使うほど ゲームが すすみ、クイズで OTC医薬品や 法律の 知識も まなべます。不要なときは「見た目と音の設定」で かくせます。

ふだん使うもの

データの控え(バックアップ)機種変更の引き継ぎにも。月1回の保存がおすすめ

在庫・商品マスタ・各種設定をファイル1つに保存できます。機種変更やアドレス変更の際は、変更前に「控えを保存」し、変更後の画面で「控えから復元」してください。

在庫の動き入庫・出庫・棚卸しの記録

数量の ＋/−、登録、削除、棚卸しで 在庫数が 変わると 自動で記録されます(最新500件)。

店舗間の備蓄共有他店の在庫をさがす・自店の在庫を見せる
とみながグループ 店舗間の備蓄情報共有です。アップロードすると、共有サーバーに接続しているすべての店舗が薬局名・品目・在庫数を閲覧できます。

備蓄をさがす

はじめに一度だけ設定

薬局情報薬局名・住所(備蓄共有で使います)
注文サイト(e健康ショップ・order-epi)🛒ボタンで開くサイトとID・パスワード

在庫リストの 🛒 を押すと、発注先が「e健康ショップ」の商品は e健康ショップの管理ページを、一覧にある卸(アステム・アルフレッサ等)や発注先が空欄の商品は order-epi を別のウィンドウで開きます。発注先を「その他」で自由に書いた商品は、メーカー指定の方法で発注するよう お知らせを出します。

IDとパスワードは この端末の中だけに保存されます(データの控え・備蓄共有には含まれません)。他の人も使う端末では入れないでください。

別のサイトの入力欄に このアプリから文字を書き込むことは、ブラウザの安全のしくみで禁止されています。そのため、開いたあとに出る「IDをコピー」「パスワードをコピー」で貼り付けてください。毎回の入力を省くには、ブラウザ(Chrome・Safari)の「パスワードを保存」を使うのが確実です。一度保存すれば、次からは自動で入力されます。

商品名の自動取得スキャン時に商品名を自動で入れる

楽天ウェブサービス(Rakuten Developers)の Application ID と Access Key を設定すると、スキャンしたJANコードから商品名を自動取得します。

※Yahoo!はブラウザから直接呼び出せない仕様のため、上の「店舗間の備蓄情報共有」で共有サーバーURLを設定している場合のみ利用できます(サーバー経由で取得します)。未設定の場合は自動的に楽天market等で検索します。

検索順: Yahoo!ショッピング → JANCODE LOOKUP → 楽天市場 → Open Food Facts(キー不要) → 手入力。Yahoo!はメーカー名と商品分類まで取得できるため、設定を強くおすすめします。キーはこの端末にのみ保存されます。
